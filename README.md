## 01–03. Project setup, Expo Go, and frameworks

- **Project setup:** [Create the blank TypeScript app](https://aitechforyou.com/articles/react-native-project-setup).

- **Frameworks:** [Understand Expo and React Native](https://aitechforyou.com/articles/react-native-frameworks-overview).
- **Snapshot:** The first three articles share this branch.
- **Name:** DailyList replaces the Taskly name used in the articles.

## What this snapshot contains

- **App:** A blank TypeScript project named DailyList.
- **Dependencies:** Yarn Classic records the dependency versions in yarn.lock.
- **Entry point:** expo/AppEntry.js starts App.tsx.
- **Expo Go:** Runs the existing app without changing its code.
- **Framework overview:** Explains the existing setup without changing its code.

## Run this snapshot

- **Branch:** Switch to the shared snapshot.

```sh
git switch 01-02-03
```

- **Dependencies:** Install the versions recorded in this branch.

```sh
yarn install --frozen-lockfile
```

- **App:** Start Expo and open the app in Expo Go.

```sh
yarn start
```
